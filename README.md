A production-grade demonstration website representing ScaleNova's **EliteOS Tier** for tertiary hospitals, super-specialty outpatient clinics, and surgical daycare chains.

## Features
- **Clinical Reassurance Design System**: Hospital Crisp White (`#FFFFFF`), Clinical Marine Teal (`#0D9488`), and Deep Navy (`#0F172A`).
- **Interactive Calming Vital Pulse Canvas**: Multi-layer physiological ECG sine wave animation with gentle pointer interaction.
- **12 Rich Content & Operational Pages**:
  - `index.html` (Hero, vital pulse wave, clinical specialties, hospital stats)
  - `about.html` (Medical leadership, clinical advisory board, NABH accreditation)
  - `specialties.html` (Cardiology, Robotic Orthopedics, Neurosciences, Oncology)
  - `specialist-detail.html` (Deep dive on Dr. Arvind Swaminathan, Chief of Minimally Invasive Cardiac Surgery)
  - `treatments.html` (Mako robotic arthroplasty, TAVR, single-incision laparoscopy)
  - `facilities.html` (Class 10,000 modular laminar flow OTs & 24/7 cardiac ICU)
  - `patient-experience.html` (Cashless TPA insurance desk & international patient concierge)
  - `wellness.html` (Executive, Comprehensive Heart, and Whole-Body Master checkups)
  - `book-appointment.html` (Doctor consultation & diagnostic slot booking form)
  - `health-insights.html` (Clinical articles on cardiology, orthopedics, and oncology)
  - `contact.html` (Hospitals in Bengaluru, Hyderabad, and Mumbai)
  - `privacy.html` (Protected health information & DPDP compliance)
- **Shared Integration Gateway**: Routes directly to Google Apps Script `DEMO-05`, updating Google Sheet `Demo5_Healthcare` and Frappe CRM (`demo.scalenovasys.com`).

## Quick Start
```bash
npm install # optional
npm run dev # runs serve at port 3005
npm test    # runs system validation test
```
